# 京剧剧本降维聚类算法说明

## 整体流程

```
原始剧本 JSON
    ↓
① 规则分类（一级 + 二级）
    ↓
② 特征工程（235维）
    ↓
③ Supervised UMAP → 2D坐标
    ↓
④ 包络圆计算
    ↓
drama_embeddings.json
```

完整可复现脚本：`脚本/dimension_reduction_pipeline_final.py`

---

## ① 分类方案

**核心原则**：京剧剧本高度角色中心化，角色名是最可靠的分类信号。完全抛弃原始 `drama_type` 标签（经验证存在约10-15%误标）。

### 一级分类（8类）

三层打分机制，取最高分类别，同分时按优先级消歧：

| 层 | 信号来源 | 权重 |
|----|---------|------|
| 第一层 | 角色名字典匹配（characters字段） | +3分/个 |
| 第二层 | 情节关键词匹配（title + plot_summary） | +1分/词 |
| 兜底 | 无命中 → 归入生活风俗剧 | — |

**优先级**（同分时高优先级获胜）：
神话神魔 > 公案清官 > 英雄侠义 > 历史风云 > 宫廷权谋 > 爱情婚姻 > 家庭伦理 > 生活风俗

### 二级分类（系列群）

同一机制在系列层面再次匹配，角色名命中即归入对应系列。未命中的归入"其他XX"，不画包络圆。

## ② 特征工程（共235维）

### 各特征组

| 特征组 | 维度 | 权重系数 | 作用 |
|--------|------|---------|------|
| LDA主题向量 | 30 | ×1.2 | 捕捉文本语义主题（已清洗URL噪音） |
| 角色行当分布 | 9 | ×0.8 | 老生/小生/旦/老旦/武旦/净/红生/丑/武生 比例 |
| 叙事特征 | 5 | ×0.6 | 场次数、篇幅、角色数、西皮比例、二黄比例 |
| **角色名二值特征** | **191** | **×8.0** | **系列分离核心信号** |

标准化：LDA/行当/叙事三组各自经 `StandardScaler` 归一化后再乘权重系数；角色名特征为原始二值（0/1）直接乘权重。

### LDA详情

- 词汇量：8000词，min_df=3，max_df=0.85
- 主题数：30个，max_iter=30，online learning
- 分词：jieba，去除停用词、URL行（含 `http`/`TCPDF`）、长度<2的词

### 角色名二值特征

为27个具名系列各定义标志性角色（共191个不重复角色名）。每个剧本生成一个二值向量：该角色出现则为1，否则为0。

此特征权重最高（×8.0），原因：三国群和春秋战国群的角色完全不同（刘备/曹操 vs 项羽/荆轲），而LDA中二者均大量使用战争词汇、难以区分。角色名特征直接编码系列身份，有效解决同大类内系列混叠问题。

## ③ Supervised UMAP

### 参数

```python
umap.UMAP(
    n_components=2,
    n_neighbors=20,
    min_dist=0.08,
    metric='cosine',
    random_state=42,
    target_metric='categorical',
    target_weight=0.85,   # 85%监督信号，15%无监督结构
)
```

### 监督信号

使用**35个系列标签**（而非8个大类标签）作为监督信号。

使用大类标签时，UMAP只分离8个大类，类别内部（如三国群 vs 春秋战国群）完全无分离信号。使用系列标签后，UMAP直接优化35个系列的空间分离，大类分离作为副产品自然形成。

### 坐标归一化

UMAP输出的原始坐标线性归一化到 [-1, 1]：

```
x_norm = (x - x_min) / (x_max - x_min) * 2 - 1
```

## ④ 包络圆计算

**目标**：为每个具名系列找到一个覆盖尽量多点的小圆，上限半径 R_MAX = 0.28（约为整个坐标空间宽度的14%）。

**密度最优算法**：

1. 生成候选圆心集合：所有点 + 质心 + 每对点的中点（最多取前8个点的两两组合）
2. 对每个候选圆心，统计半径 R_MAX 内的点数
3. 选覆盖点数最多的圆心
4. 实际半径 = 该圆心到圆内所有点的最大距离（≥0.025的下限）

**不画包络圆的系列**：所有"其他XX"系列和"市井百态"（零散/兜底剧本）。
