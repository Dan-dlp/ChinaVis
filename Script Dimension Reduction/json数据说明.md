# drama_embeddings.json 数据说明

输出文件：`Script Dimension Reduction/drama_embeddings.json`

---

## 顶层结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `total` | number | 剧本总数，1473 |
| `categories` | string[] | 8个一级类别名称列表 |
| `category_counts` | object | 各一级类别的剧本数量 |
| `series_hull` | object | 各系列的包络圆参数（键为系列名） |
| `series_cat` | object | 系列名 → 所属一级类别 的映射 |
| `points` | object[] | 每个剧本的数据点，共1473条 |

---

## points 字段说明

每条记录对应一个剧本：

```json
{
  "id": "01001001",
  "title": "空城计",
  "x": 0.7796,
  "y": 0.0680,
  "category": "历史风云剧",
  "series": "三国群",
  "scene_count": 6,
  "character_count": 7,
  "pages": 5
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 剧本唯一编号，对应 `structured/scripts/{id}.json` |
| `title` | string | 剧目名称 |
| `x` | number | UMAP降维后的横坐标，归一化到 [-1, 1] |
| `y` | number | UMAP降维后的纵坐标，归一化到 [-1, 1] |
| `category` | string | 一级类别（8类之一） |
| `series` | string | 二级系列（如"三国群"、"水浒群"），零散剧本为"其他XX" |
| `scene_count` | number | 场次数 |
| `character_count` | number | 角色数 |
| `pages` | number | 原始文档页数（反映篇幅长短） |

---

## series_hull 字段说明

仅包含有具名系列（不含"其他XX"和"市井百态"）的包络圆参数：

```json
{
  "三国群": {
    "cx": 0.7796,
    "cy": 0.0680,
    "r": 0.1965,
    "n": 239,
    "covered": 239
  }
}
```

| 字段 | 说明 |
|------|------|
| `cx` | 包络圆圆心横坐标（与 points.x 同坐标系） |
| `cy` | 包络圆圆心纵坐标 |
| `r` | 包络圆半径（与坐标系单位一致） |
| `n` | 该系列的剧本总数 |
| `covered` | 包络圆内实际覆盖的剧本数 |

> 注：圆心由密度最优算法确定——遍历所有点及中间点作为候选圆心，选覆盖点数最多的位置，半径上限 R_MAX = 0.28。
